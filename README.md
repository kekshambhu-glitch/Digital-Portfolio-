## 🌟 Overview

**My AI Workspace** is a responsive, modern personal AI dashboard designed with a **Dark Charcoal theme and Blue/Violet accents**. It unites daily AI tools, a library of parameterized prompt engineering templates, a grounded academic knowledge base, and an interactive 6-build project roadmap into one cohesive workspace.

Configured cards for your core AI workflow:
- **ChatGPT (OpenAI)**: Concept explanation, numerical reasoning, brainstorming, and code drafting.
- **Gemini Notebook (NotebookLM / Google AI)**: Grounded study assistant digesting lecture PDFs and textbooks without hallucination.
- **Perplexity (Perplexity AI)**: Real-time search engine with verified citations for academic research.

## 🖥️ How to Preview Locally

### Option A: Direct Browser Preview (Simplest)
1. Open File Explorer to `C:\Users\Hp\Desktop\Builds`.
2. Double-click **`index.html`** or right-click and select **Open with > Chrome / Edge / Firefox**.
3. All functionality works out of the box with no installations required.

### Option B: Local Python Web Server
If you prefer running via a local server:
1. Open PowerShell or Command Prompt in this folder:
   ```powershell
   cd C:\Users\Hp\Desktop\Builds
   ```
2. Start Python's built-in lightweight HTTP server:
   ```powershell
   python -m http.server 8000
   ```
3. Open your browser and navigate to:
   [http://localhost:8000](http://localhost:8000)

## 🌐 How to Share Your Project

You have several easy, safe ways to share this workspace whenever you are ready:

1. **Local ZIP Archive**:
   - Right-click the `Builds` folder > **Send to > Compressed (zipped) folder**.
   - Share with classmates, professors, or mentors. They can extract and run `index.html` immediately.
2. **GitHub Repository**:
   - Initialize git: `git init`
   - Commit files: `git add .` and `git commit -m "Initial commit of My AI Workspace"`
   - Push to your GitHub profile as a featured repository for internship recruiters.
3. **GitHub Pages (Free Hosting)**:
   - In your GitHub repository settings, enable **GitHub Pages** from the `main` branch.
   - Your workspace will have a live public URL (e.g. `https://yourusername.github.io/my-ai-workspace`) that you can showcase on your resume and LinkedIn.
   *(Note: Nothing will be deployed or published automatically without your explicit confirmation.)*
